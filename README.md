## ✨ Snap & Report

**Snap & Report** is a citizen-facing platform for reporting suspected illegal parking.

The system allows citizens to submit vehicle images and location information, while AI-powered image processing assists with vehicle and number-plate detection. Authorized officers can review reports and manage the verification workflow through a dedicated dashboard.

## 🛠️ Run Locally

```bash

cd snap-and-report-landing

npm install

npm run dev
```

Build for production:

```bash
npm run build
```
